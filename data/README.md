# Datos locales

Coloca aquí `Customer Data.csv` para que la aplicación lo use como dataset
predeterminado. Los archivos CSV de este directorio están excluidos de Git
porque pueden contener registros financieros o identificadores de clientes.

Si no tienes autorización para almacenar el dataset en el equipo o compartirlo,
no lo copies aquí: utiliza un conjunto de datos autorizado o carga el archivo
desde la aplicación en un entorno controlado.
